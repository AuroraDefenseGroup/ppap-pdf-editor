# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A Windows desktop PDF viewer/editor (PySide6 + PyMuPDF) for building PPAP / FAI ballooned inspection drawings. The whole app is the single file `ppap_pdf_editor.py`; `README.md` describes the user-facing features.

## Commands

- **Build the distributable:** `build.bat`. On first run it creates `.venv` with Python 3.13 (`py -3.13`) and installs `requirements.txt` on every run (PyMuPDF, PySide6, PyInstaller and the `winrt-*` packages for OCR). It then regenerates `icon.ico` via `make_icon.py` and runs PyInstaller. Output: `dist\PPAP PDF Editor\PPAP PDF Editor.exe` (a one-folder build; the whole folder is what gets copied to other PCs).
- **Run from source:** `.venv\Scripts\python ppap_pdf_editor.py [file.pdf]`. The first non-flag argument is opened on startup.
- There are no tests, linter or formatter configured.

PyInstaller options live in `build.bat` (`--exclude-module tkinter/pymupdf.layout/numpy`, `--windowed`). `PPAP PDF Editor.spec` is regenerated by each build and is gitignored, so edit `build.bat` rather than the spec.

## Architecture

**Two kinds of edits, kept separate:**
1. **Markups** (balloons, text boxes, rectangles, lines/arrows) live only as Qt scene items while editing. Each item wraps a plain dict `it.d` (`type`, `page`, geometry, style; see `DEFAULT_BALLOON` / `DEFAULT_MARKUP`). `ITEM_CLASSES` maps `type` to the `MarkupItem` subclass, and items are parented to the `PageItem` for their page. `MainWindow.items` is the authoritative list.
2. **Content edits** (Edit Text, Remove Text, Whiteout) change `self.doc` (the PyMuPDF document) immediately via redaction annotations plus `apply_redactions`, then `insert_text` with a Base-14 font (`BASE14`). The original embedded font is never reused.

**Undo/redo** (`push_undo` / `_swap_state`): each entry is `(markup_snapshot, doc_bytes_or_None)`. Call `begin_markup_change()` before a markup-only change, or `begin_content_change()` before touching `self.doc`; the latter snapshots the whole PDF with `doc.tobytes()`. On undo of a content change the document is reopened from bytes and page renders are invalidated. Any new editing operation must call one of these first or it won't be undoable.

**Save round-trip** (`build_output` / `extract_saved_markups`): Save copies the doc, writes every markup as standard PDF annotations titled `TAG` ("PPAP-Editor") via `write_markup`, and embeds the markup dicts as JSON in the embedded file `EMB_NAME` (`ppap_markups.json`). On open, if that embedded file exists, its markups are restored as live items and both the embedded file and the `TAG` annotations are deleted, so they aren't duplicated. Export Flattened skips the embed and calls `out.bake()` so markups become page content. Keep the `TAG` / `EMB_NAME` scheme backward compatible, because saved customer drawings depend on it.

**Coordinates:** Markup dicts and scene items use *displayed* (rotation-applied) page coordinates in PDF points. Convert with `page.derotation_matrix` when writing to the PDF (`write_markup`, `redact_area`, `_to_unrot`). Rotated pages are the usual source of placement bugs.

**Rendering:** `PdfView` (QGraphicsView) holds one `PageItem` per page stacked with `PAGE_GAP`. Pages are rendered lazily for visible pages only (`request_render` / `render_pending`), capped at `MAX_PIXMAP` px. Call `invalidate_page(i)` after changing a page's content.

**OCR** (`ocr_text` / `ocr_pixmap`) uses Windows' built-in `Windows.Media.Ocr` through the `winrt` packages; there is no Tesseract. It reads only and is not undoable. `get_pixmap`'s `clip` is in *displayed* coordinates, so the selection rect is passed as is; sideways text is handled by also trying 90° and 270° and keeping the best `ocr_score` (which favours upper case, as on drawings). `fix_ocr_digits` turns O into 0 inside numbers. If the `winrt` import fails, `OCR_IMPORT_ERROR` is set and the tool reports it instead of crashing.

**Settings** persist through `QSettings` (organization "ADG Engineering", app "PPAP PDF Editor"), including the last directory, window geometry and balloon/markup style JSON.
